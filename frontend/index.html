The Challenge & Our Breakthrough

Why Multi-Source Customer Feedback is Broken

Traditional SaaS teams manually check disparate portals with inconsistent rating systems, zero deduplication, and massive comment noise.

❌ The Problem Statement
  • ✕ Siloed Platforms: Feedback is scattered across YouTube comments, Play Store reviews, Maps ratings, and Instagram DMs/comments.
  • ✕ Inconsistent Schemas: Some sources have 5-star ratings; others (like YouTube) have likes and nested reply threads with no star ratings.
  • ✕ Duplicate & Quota Risk: Repeated synchronization pulls redundant data and rapidly drains official third-party API quotas.
  • ✕ No Actionable Insights: Raw text is overwhelming for CX and Product managers without automated theme classification.
✨ How We Solve It (Feedback Intelligence)
  • ✓ Unified Normalization Engine: Every source maps into a standardized Feedback schema preserving original timestamps and metadata JSONB.
  • ✓ Idempotent Deduplication: Enforces composite unique constraint (business_id + source + external_id) to guarantee zero duplicates.
  • ✓ Official API-First Architecture: Direct server-side HTTPX integration with Google YouTube Data API v3 and complete reply thread pagination.
  • ✓ Chattermill-Style AI Themes: Automatically aggregates customer sentiment into actionable topics, volume trajectories, and key growth drivers.
System Architecture

4-Step Ingestion & Intelligence Pipeline

From raw API endpoints to verified customer intelligence.

Step 01

Multi-Source Ingestion

Fetches top-level threads & deeply nested replies via official YouTube Data API v3, Google Maps, and Store APIs.

Step 02

Schema Normalization

Converts disparate timestamps, text fields, author profiles, and engagement counts into a unified feedback payload.

Step 03

Idempotency & Deduplication

Prevents redundant database insertion and preserves API quota limits across recurring 2-hour sync intervals.

Step 04

AI Theme Discovery

Clusters customer feedback into positive/neutral/negative themes, surfacing actionable product insights.
